# XPlay Designs

Original digital designs sold on [XPlay](https://xplay.mrsaqlainproductions.com/)
by MR SAQLAIN PRODUCTIONS. Every design is made for XPlay — no stock,
no clipart, no copyrighted material.

## Layout

- `files/<tag>/design.zip` — the deliverable: high-resolution PNG
  (300 DPI, 4000px long edge) + print-ready PDF (A4) + LICENSE.txt.
  Social kits also include the story-size PNG.
- `artwork/<tag>/logo.png` — 512×512 low-res preview (listing icon).
- `artwork/<tag>/feature.png` — 1024×500 low-res preview (store banner).

The preview art is low-resolution only. The full-resolution files are
inside the zip, revealed to the buyer after purchase.
